Water sensor, calibration & filtering → ESP32_A

Changes are sent over ESP-NOW and saved by ESP32_A. A reboot of ESP32_A is not normally required.

Mirror person detection

Use OFF distance slightly higher than ON distance to prevent flicker. Manual Mirror Light controls stay available on the dashboard.

Buzzer

Beeps per second ≈ 1000 ÷ beep period. Intensity uses PWM and is approximate on active buzzers; some modules only click instead of changing volume.

OLED display

Approximate 128×64 preview. Default layout is percent size 5, litres size 2, and bottom text size 1.

History storage

Retention is automatic: the oldest CSV lines are removed when the configured window is exceeded. Storage is LittleFS on ESP32_B.

Admin session & passcode

The default passcode is 14789. This is local-network protection only; it is not internet-grade security.

No unsaved changes

Maintenance actions

Rebooting ESP32_A temporarily drops water data. Rebooting ESP32_B also drops this dashboard for a few seconds.
